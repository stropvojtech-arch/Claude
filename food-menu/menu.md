# Home menu

The data behind the Food Menu artifact. Edit this file and republish; the page reads it on load.

- Prices are in DKK.
- **Store items** are what you buy. Each has a short **Key** that dishes use to point at it.
- Each `##` heading under the store items is a menu section (Breakfast, Lunch, Dinner). Each `###` is a dish.
- In a dish's ingredient table, **Cost** is the cost per portion. **Share of pack** is optional: how much of one pack a portion uses (0.5 = half). Leave it empty and it's worked out as Cost ÷ pack price. **Shown as** is optional and replaces the product name on the dish card.
- Two items in one row are joined with `+`, e.g. `salt + pepper`.
- The method is the numbered list under each dish.
- Don't use the `|` character inside table cells.

Method:

### Pizza Crudo

- Key: pizza
- Price: 23.03
- Description: Homemade dough, tomato sauce, mozzarella, fresh tomato and prosciutto
- Nutrition: 1260 kcal, 49 g protein, 158 g carbs, 47 g fat
- Nutrition note: Includes the oil and sugar in the dough.
- Batch note: The dough and the sauce are each made for 3 pizzas. Amounts are for one pizza, with the full batch in brackets.

| Item | Amount | Cost | Share of pack | Shown as |
|---|---|--:|--:|---|
| flour | ~167 g (batch 500 g) | 0.83 |  |  |
| yeast | ⅙ cube (batch ½ cube) | 0.25 |  |  |
| oil | ~17 ml (batch 50 ml) | 1.45 |  |  |
| cantom | ⅓ can (batch 1 can) | 2.32 |  |  |
| sugar | 1⅔ tbsp (batch 3 dough + 2 sauce) | 0.16 |  |  |
| salt | 1⅓ tbsp (batch 3 dough + 1 sauce) | 0.12 |  |  |
| oregano | 1 tbsp (batch 3 tbsp) | 0.54 |  |  |
| mozz | 1 ball | 7.95 |  |  |
| prosc | 2 slices | 6.08 |  |  |
| tomato | 1 tomato | 3.33 |  |  |

Method:

1. Dough (makes 3): stir ½ cube of yeast and 3 tbsp sugar into warm water. Let it sit about 5 min.
2. Add the flour and 3 tbsp salt and mix. Before it fully comes together, add the 50 ml olive oil, then mix until it's no longer sticky. Add flour as needed.
3. Rub a little olive oil on top so it doesn't stick to the bowl. Cover and put it in the fridge overnight. If you have the patience, 3 days gives the best result.
4. Sauce (makes 3): bring 1 can of tomatoes to a light boil. Add 2 tbsp sugar, 1 tbsp salt and 3 tbsp oregano and cook it. Pour into a container. It's ready to use straight away.
5. For one pizza: stretch a third of the dough and spread a third of the sauce. Top with 1 mozzarella ball, 2 slices of prosciutto and 1 sliced tomato.
6. Bake as hot as your oven goes (250 °C+) for 8–12 min, until blistered.
